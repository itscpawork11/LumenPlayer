# Visual Design Concept — VlcRebuild (Phase 1)

## Name (temporary)
**Lumen Player** (temporary project name; independent identity, no VLC trademarks).

## Palette
- Background: `#0F1115` (deep charcoal)
- Surface 1: `#171A21`
- Surface 2: `#1F232C`
- Border: `#2A2F3A`
- Text Primary: `#E6EAF2`
- Text Secondary: `#9AA4B2`
- Accent (distinctive): `#4FD1C5` (teal) — hover `#38B2AC`, pressed `#2C7A7B`
- Danger: `#F56565`

## Typography
- Font: Segoe UI Variable (fallback Segoe UI), sizes 12/14/16/20.
- Headings semibold, body regular, captions secondary color.

## Layout
- Top bar (48px): title + window commands region.
- Sidebar (260px, collapsible visual region) for future media/playlist.
- Main viewing area: primary focus, empty state with subtle grid.
- Bottom control region (72px): reserved placeholders (non-functional).
- Status line: static status text.

## Rationale
Restrained dark theme with a single teal accent for recognizability; layered surfaces for depth without heavy effects; consistent spacing (4/8/12/16/24) and 8px corner radius. No playback functionality in Phase 1.
